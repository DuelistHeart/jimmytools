# Configuration

Open the config screen with the **Open JimmyTools Config** key (++m++ by default) or through Mod Menu.
Settings are saved when the game closes.

## ChatUtils

| Option | Default | Description |
|---|---|---|
| Enable LevelUp Messages | off | Writes level-up notices to chat. |
| Enable Names command | off | Runs `/names` when you join the server. |
| Names command option | `/names character` | Which `/names` variant to run: `on`, `off` or `character`. |

## CustomTab

| Option | Default | Description |
|---|---|---|
| Enable Custom Tablist | off | Replaces the vanilla tab list with the scroll-style one. |
| Scroll Open Speed | 3 | How fast the scrolls open (1–12). |
| Scroll Close Speed | 8 | How fast the scrolls close (1–12). |

## Transformation

A button starts the [transformation setup](features/transformations.md). The skins it records are stored in the config file.
