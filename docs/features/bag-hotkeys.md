# Bag Hotkeys

Open the server's inventory bags with one key press instead of clicking through your inventory.

| Bag | Default key |
|---|---|
| Red | ++arrow-up++ |
| Blue | ++arrow-right++ |
| Green | ++arrow-down++ |
| Bag Of Holding | ++arrow-left++ |

Each key opens your inventory and clicks the matching crafting-grid slot for you. Rebind them in *Options → Controls → Key Binds → JimmyTools*.
