# Bingo

In-game support for playing Bingo at the Snake-Eyes Lounge & Teahouse.

Press ++b++ (or your own binding) to open the **Bingo Screen**. From there you can:

| Button | Action |
|---|---|
| Generate Cards | Creates new bingo cards, up to the *Max Cards* setting. |
| Clear Marks | Removes every marker from your cards. |
| Reset | Resets the cards. |
| Item List | Opens the **Bingo Items** screen with the possible items. |

Click a square to place or remove a marker.

## Customizing

* **Colors** – set the card background and grid colors in the [config screen](../configuration.md#bingo).
* **Card numbers** – turn on *Show Bingo Card Numbers* to label each card.
* **Sounds** – each of placing, removing, clearing and generating has its own toggle.
* **Markers** – the marker image is `assets/jimmytools/ui/marker.png`, so a resource pack can replace it.
