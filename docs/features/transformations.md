# Transformations

For characters that change appearance (mermaids, magical girls, vampires and so on). Once set up, one key
swaps between your regular skin and your transformed skin.

## Setting up

1. Open the config screen and go to **Transformation**.
2. Press **Set Up Character Transformation**. The config closes and a chat message asks you to transform manually.
3. Run `/skin <url>` with your transformation skin.
4. JimmyTools records both skins and tells you which key reverts the change.

## Using it

Press ++k++ (or your own binding) to swap between the two skins. The mod sends the matching `/skin` command for you.

!!! note
    Transformations work with skins that are set by URL, which is how `/skin <url>` works.
