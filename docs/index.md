# JimmyTools

JimmyTools is a [Fabric](https://fabricmc.net/) mod that adds quality-of-life and utility features for the
**Lords of Minecraft 2 (LoM2)** server. It started as a way to keep character transformations tidy and has
grown to cover bingo, bag hotkeys, a custom tab list and more.

[Install it](installation.md){ .md-button .md-button--primary }
[Download on Modrinth](https://modrinth.com/mod/jimmytools){ .md-button }

## Features

| Feature | What it does |
|---|---|
| [Bingo](features/bingo.md) | Play Bingo at the Snake-Eyes Lounge & Teahouse with in-game cards. |
| [Bag Hotkeys](features/bag-hotkeys.md) | Open your bags with a single key press. |
| [Transformations](features/transformations.md) | Swap between a character's regular and transformed skin with one key. |
| [Custom Tab List](features/custom-tablist.md) | A scroll-styled tab list showing players, nearby characters and the current district. |
| [Level-Up Messages](features/level-up-messages.md) | Level-up notices are also written to chat. |
| [Startup Commands](features/startup-commands.md) | Run `/names` automatically when you join. |

Everything is configurable from the in-game [config screen](configuration.md).
