# Installation

## Requirements

* Minecraft **26.2** with [Fabric Loader](https://fabricmc.net/use/) 0.19.5 or newer
* [Fabric API](https://modrinth.com/mod/fabric-api)
* [owo-lib](https://modrinth.com/mod/owo-lib)
* [YetAnotherConfigLib (YACL)](https://modrinth.com/mod/yacl)

Recommended: [Mod Menu](https://modrinth.com/mod/modmenu), which adds a config button to the mods list.

## Steps

1. Install Fabric Loader for Minecraft 26.2.
2. Download JimmyTools from [Modrinth](https://modrinth.com/mod/jimmytools).
3. Put the JimmyTools jar and the required mods above in your `mods` folder.
4. Launch the game and join the server.

JimmyTools is client-side only. Nothing needs to be installed on the server.

!!! note
    Features are aimed at the LoM2 server (`lords.rawb.tv`). Some, such as the startup commands, only act on that server.

## Updating

Replace the old JimmyTools jar in your `mods` folder with the new one. Your settings are kept in the
JimmyTools config file and carry over between versions.
