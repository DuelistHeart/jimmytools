# Keybinds

All keybinds are under the **JimmyTools** category in *Options → Controls → Key Binds* and can be changed there.

| Action | Default key |
|---|---|
| Open JimmyTools Config | ++m++ |
| Open Bingo Screen | ++b++ |
| Transform Skin | ++k++ |
| Open Bag (Red) | ++arrow-up++ |
| Open Bag (Blue) | ++arrow-right++ |
| Open Bag (Green) | ++arrow-down++ |
| Open Bag Of Holding | ++arrow-left++ |

The custom tab list uses Minecraft's normal *Player List* key (++tab++ by default).
